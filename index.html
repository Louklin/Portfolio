A.S.E.A.

2025 – 2026 · Undergraduate thesis

A web app that checks whether a text message is legitimate, spam, or phishing.

The problem

Scam and phishing texts are a common way to steal money and personal information in the Philippines. They're written in English, Filipino, or a mix of both, so simple keyword filters miss many of them.

Features

  • Paste or type a text message to check it
  • Labels each message as legitimate, spam, or phishing
  • Understands English, Filipino, and Taglish messages
  • Built for the PNP Regional Anti-Cybercrime Unit 3

How it works

The app runs a fine-tuned BERT language model. We compared several models, and multilingual BERT (mBERT) gave the best results.

My role

Data Analyst. I collected, cleaned, and prepared the text message dataset the model was trained on.
